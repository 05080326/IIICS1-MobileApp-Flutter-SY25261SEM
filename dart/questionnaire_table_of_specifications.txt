SAMPLE ESSAY ANSWER - PART III
========================================================================

EXPLANATION OF 'var', 'final', AND 'const' IN DART:

1. 'var' KEYWORD:
   - Used for type inference
   - Variable can be reassigned
   - Type determined at compile time
   
   Example:
   var name = "John";     // String inferred
   name = "Jane";         // Can be changed
   var age = 25;          // int inferred

2. 'final' KEYWORD:
   - Variable can only be set once
   - Value assigned at runtime
   - Cannot be reassigned after initialization
   
   Example:
   final currentTime = DateTime.now();  // Set at runtime
   final String userName = "Admin";     // Cannot change

3. 'const' KEYWORD:
   - Compile-time constant
   - Value must be known at compile time
   - Immutable and cannot be changed
   
   Example:
   const pi = 3.14159;           // Compile-time constant
   const List<int> numbers = [1, 2, 3];  // Immutable list

WHEN TO USE EACH:
- Use 'var' when you need a mutable variable with type inference
- Use 'final' when you want to set a value once at runtime
- Use 'const' when you have a compile-time constant value
